04 — Components

Component Breakdown

Detailed overview of every component, its role, and key features.

Component Type Description & Features Key Dependencies
Preloader.tsx
components/Preloader.tsx
 UX Full-screen branded loading screen displayed for 2.8 seconds. Features an animated SVG infinity loop with a glowing gradient stroke tracer, brand name reveal, and a pulsing tagline. Prevents scroll during load, then fades out with cubic-bezier ease. framer-motion, AnimatePresence, useEffect, useState
LandingNavbar.tsx
components/landing/LandingNavbar.tsx
 Nav Fixed top navigation for the main landing page. Supports scroll-aware glassmorphism (transparent → frosted blur on scroll). Includes desktop links, a gradient CTA button, and an animated hamburger mobile menu. Slide-in animation on mount. framer-motion, AnimatePresence, lucide-react (Menu, X), useState, useEffect
LandingHero.tsx
components/landing/LandingHero.tsx
 Hero Full-viewport hero with 3 layered canvas effects: (1) warp starfield with 280 stars + mouse-connected constellations, (2) shooting meteors that auto-spawn and fire on mouse swipe/click, (3) nebula pulse glows. Astronaut PNG with mouse parallax. Glass info card + stats card. "Explore Solutions" CTA button. Canvas API, framer-motion, next/image, useRef, useEffect
Hero.tsx
components/Hero.tsx
 Legacy Alternative hero with 120-particle field + connecting lines on a canvas. Features a 3D tilt orb (mouse-driven perspective), orbiting energy particles, floating stat cards, social proof with avatars. Not used on the current main route. Canvas API, framer-motion, useRef
InfinityFlow.tsx
components/InfinityFlow.tsx
 Section Services section with 3 glassmorphism cards (Web Dev, Graphic Design, Video Editing). Each card has: icon badge, stat badge, service tags, hover glow + translateY effect, large number watermark. Stagger animation on scroll into view. framer-motion (motion, whileInView), lucide-react (Code2, Palette, Film)
WhyChooseUs.tsx
components/WhyChooseUs.tsx
 Section 6 reason cards in a 3×2 grid with 3D mouse-tilt effect per card. Stats banner (50+, 98%, 3×, 24/7). Cards: Creative Innovation, Fast Delivery, Premium Quality, Modern Tech Stack, Trusted, Global Reach. Each with unique accent color + scroll-triggered entry. framer-motion (useInView), lucide-react (Lightbulb, Zap, Award, Cpu, Shield, Globe)
Portfolio.tsx
components/Portfolio.tsx
 Section Filterable portfolio grid (All / Web / Design / Video). 6 project cards with hover zoom + overlay + CTA reveal. Click opens a spring-animated modal with project details, description, stat, and tags. Projects: NexaCloud, Aura Brand, Orbital Film, CryptoVault, Luminary UI, Nova Social. framer-motion (layout, AnimatePresence), lucide-react (X, ExternalLink, Globe, Layers, Play, ArrowRight)
Testimonials.tsx
components/Testimonials.tsx
 Section Dual infinite marquee rows — row 1 scrolls left-to-right, row 2 right-to-left. 5 clients from India, UK, Sri Lanka, Singapore, UAE. Each card has: star rating, quote text, avatar, name, country flag, role. Pauses on hover. Hardware-accelerated CSS animation. framer-motion (useInView), lucide-react (Star, Quote), CSS keyframes
FinalCTA.tsx
components/FinalCTA.tsx
 Contact Contact section with 2-column layout. Left: description + 3 contact info cards (Email, WhatsApp, Location) + CTA buttons. Right: live contact form with Name, Email, Service (dropdown), Project Details. Submitted to web3forms API. Success state with animated checkmark. Bottom stats bar. framer-motion, lucide-react, fetch (web3forms.com), useState, async/await
Footer.tsx
components/Footer.tsx
 Layout 4-column footer: Brand (logo + tagline + social icons), Services links, Company links, Connect info. Social icons: Facebook, Instagram, LinkedIn, Email. Copyright bar with gradient brand name. "Crafted with ∞ creativity in Sri Lanka 🇱🇰". next/image, React.SVGProps
SmoothScroll.tsx
components/SmoothScroll.tsx
 Utility Wraps the entire app with Lenis smooth scroll. Initializes Lenis instance on mount, runs RAF loop, and cleans up on unmount. Provides buttery smooth page scrolling across all sections. lenis, useEffect, useRef

07 — Interactions

Animations & Interactions

Every interaction is designed to delight. The site uses multiple animation layers.

🌌 Canvas Particle Systems

  • 280-star warp starfield with depth (z-axis)
  • Mouse-connected constellations (cyan lines)
  • Shooting meteors on timer (auto) & on fast swipe
  • 3-meteor burst on any click anywhere
  • All via requestAnimationFrame for 60fps

🎭 Framer Motion Animations

  • Scroll-triggered section entry (whileInView)
  • Stagger children animations on service cards
  • Spring-physics modal open/close (AnimatePresence)
  • Fade + slide-in for all headings (opacity + y)
  • Preloader infinity SVG stroke-dashoffset loop

🖱️ Mouse Interaction

  • Astronaut parallax (follows cursor 20px offset)
  • 3D tilt on hero orb (Hero.tsx) via perspective CSS
  • 3D tilt on Why Choose Us reason cards
  • Hover state on all cards (translateY, glow, border)
  • Navbar glassmorphism on scroll (blur + border)

📜 CSS Animations

  • animate-spin-slow — 20s rotating rings
  • animate-spin-reverse — 15s counter-rotation
  • animate-float — 6s vertical sine wave
  • animate-pulse-glow — 3s glow pulsing
  • Dual marquee rows (38s LTR, 42s RTL) for testimonials

🔤 Typography Animations

  • Letter-spacing expansion on INFAVOUR brand name
  • Opacity pulse on "Stitching Digital Space" in preloader
  • Gradient text on headings (WebkitBackgroundClip)
  • Clamp-based fluid font sizing across breakpoints

📱 Responsive Behaviour

  • Hero: collapses to single column on <1024px, hides orb
  • Why Us: 3-col → 1-col grid on <768px
  • Contact: 2-col → 1-col on <900px
  • Footer stats: flex-column on <640px
  • Mobile hamburger menu in Navbar (animated)

Steps to get the development server running locally.

Note: The project uses Next.js 16 with React 19. Node.js ≥ 18 is recommended. All dependencies are listed in package.json. The next.config.ts is minimal and uses default Next.js settings.
